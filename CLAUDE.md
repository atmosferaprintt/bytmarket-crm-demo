# CLAUDE.md — БытМаркет CRM

CRM «БытМаркет» для рознично-оптового магазина бытовой химии и товаров для дома в Астрахани. Общение и весь интерфейс — на русском.

**Это отдельный проект.** С типографией «Атмосфера» и её CRM (`~/PrintCRM`) ничего общего нет: не брать оттуда логику, разделы, данные, названия, правила денег и ролей. В `~/PrintCRM` ничего не писать.

## Что сейчас делаем

Интерактивное демо-прототип (как «CRM Print 360»): красивое и законченное, на выдуманных, но правдоподобных данных, чтобы показать владельцу магазина. Всё локально: без внешних сервисов, без выкладки, без настоящего входа сотрудников (роли переключаются для показа).

Прочитать перед работой: `О ПРОЕКТЕ.txt`, `docs/00-original-brief.txt` (полное задание), остальные `docs/`. Старый прототип в `app/` — сырой: это список сценариев, а не основа внешнего вида. Не удалять его.

## Порядок работы

После каждого шага — показать результат и ждать «ок».

0. Первый коммит текущего состояния — «снимок до переделки».
1. **Аудит.** Пройти задание и все экраны старого прототипа, агентами по блокам. По каждому разделу: что есть, чего не хватает по заданию, что неудобно. Итог — план работ.
2. **Макеты.** Главные экраны (обзор владельца, продажа на кассе, оптовый заказ, товары, склад) — по 2–3 варианта в одном HTML-файле `*-variants.html`, открыть мне. Код — только после выбора.
3. **Каркас** на React + Vite (новая папка, старый `app/` не трогать): меню, шапка раздела, свой набор деталей — кнопка, поле, таблица, окно, боковая панель, вкладки, чип статуса, всплывающее меню «⋯». Цвета только через токены, из логотипа `assets/brand`: тёмно-синий и зелёный. Python-сервер можно оставить для сохранения демо.
4. **Демо-данные:** генератор магазина — около 1000 товаров бытовой химии с брендами, упаковками и штрихкодами; клиенты (розница, ИП, магазины); заказы, оплаты, долги, доставки и визиты представителей за 3 месяца. Пустой экран всегда выглядит сыро.
5. **Разделы** — по очереди или параллельно агентами. Каждый проверять самому: открыть в браузере, снимки на 1440 и 1280 px, для курьера и представителя — на телефоне; под каждой ролью; консоль без ошибок. Показать снимки до того, как сказать «готово».
6. Правки по моим замечаниям.

## Правила вида — везде одинаковые

- Один шрифт (Manrope), размеры только 11 / 12 / 13 / 14 / 16 / 20 / 24 / 32, цифры моноширинные (`tabular-nums`), суммы «12 400 ₽», в итогах без копеек.
- Один набор линейных иконок (lucide), без эмодзи.
- Белые карточки, скругление 16–20, лёгкая тень, без цветных полосок слева и цветных рамок.
- Подписи обычными буквами, без КАПСА и разрядки.
- Статус — текстом в чипе, цвет только помогает.
- Без серых пояснений под каждым числом; метка «демо» одна, в шапке.
- Одна главная кнопка на экране, остальное — второстепенные кнопки и меню «⋯».
- Таблицы как в задании: поиск, фильтры, сортировка, итоги.
- Ориентир по виду — CRM Print 360 в `~/PrintCRM-lab` (`src/ui`, `src/shell`): только посмотреть, как сделаны меню, карточки и таблицы. Код логики и разделы оттуда не брать.
