# Демо БытМаркет CRM, версия 2

Новая версия интерактивного демо: шаги 2–5 из CLAUDE.md. Старый прототип `app/` не тронут.

## Как открыть
Двойной щелчок по файлу **«Открыть демо.command»** в папке проекта. Он запустит демо и откроет браузер.

Вручную: `cd web && npm run dev`, затем открыть http://127.0.0.1:5173

Сменить сотрудника можно внизу меню: аватар и имя. На телефоне — аватар в шапке. Там же «Вернуть исходные данные»: стирает все изменения, сделанные при показе.

## Что внутри
- **Данные.** Выдуманный, но правдоподобный магазин на 5 ноября 2026 с историей с 5 августа:
  - 1000 товаров: 40 брендов, упаковки и коробки со штрихкодами EAN-13, сроки годности у части;
  - 100 клиентов: розница, магазины, кафе, клининг, рынок; точки по районам Астрахани;
  - 15 сотрудников без дублей;
  - около 490 оптовых заказов и 3150 чеков;
  - 730 платежей, 172 доставки, 650 визитов, 40 закупок.

  Выручка растёт от 3,7 млн в августе до 5,6 млн ₽ в октябре, маржа 27–28 %.

  Каждый раз генерируется одинаково. Изменения при показе сохраняются в браузере.
- **Правила учёта** перенесены из старого прототипа и проверены 71 тестом (`cd web && npm test`):
  - остатки по местам, резерв и доступно;
  - 3 коробки × 12 = 36 шт;
  - последняя единица не продаётся дважды;
  - защита от повторной отправки;
  - частичная оплата и долг;
  - отмена освобождает резерв;
  - возврат — в карантин;
  - скриншот перевода не гасит долг до подтверждения;
  - доставлено ≠ оплачено.

## Разделы
| Раздел | Что есть |
|---|---|
| Обзор | Владелец: период и сравнение, продажи с планом, прибыль и маржа, деньги, долги покупателей и поставщикам, график, сигналы. «Требует внимания»: 8 видов сигналов с причиной, цифрами, ответственным и действием. У остальных ролей — свой рабочий стол |
| Касса | Поиск и сканер, упаковки, акции, скидка с основанием в пределах роли, наличные / карта / смешанная со сдачей, печать чека, возврат по чеку, смена с пересчётом наличных, архив чеков |
| Продажи | Заказы с отдельными состояниями «Заказ / Сборка / Отгрузка / Оплата» и долгом. Новый заказ в боковой панели с условиями клиента и упаковками. Повтор с «было → стало», заявки представителей без резерва, карточка заказа с шагами, счёт и накладная на печать, возвраты, чаты (пример WhatsApp) |
| Клиенты | Список с долгом, просрочкой, лимитом и «пропустил привычный заказ». Карточка с точками, контактами, заказами, оплатами, визитами, историей. Представители и визиты. «Мой день» представителя на телефоне |
| Товары | Каталог на 1000 позиций, карточка (остатки, движения, продажи), цены и акции с проверкой наценки, каталог на телефоне |
| Склад | Остатки по местам (факт, резерв, доступно, ожидается, карантин), документы на несколько строк со сканером, пересчёт, сборка, карантин |
| Закупки | Заказы поставщикам, приёмка с расхождениями и браком, предложение на закупку с объяснением, поставщики и их долги |
| Деньги | Журнал, долги покупателей по клиентам с актом сверки, долги поставщикам с графиком платежей, расходы, кассы и счета, «Принять оплату» с распределением по заказам |
| Доставка | Очередь со статусом «ожидает назначения», маршруты курьеров, деньги курьеров, карточка доставки. Телефон курьера: «Позвонить», карта, сумма к получению, «Вручено» и «Не удалось» |
| Отчёты | Товары, клиенты, сотрудники, акции, доставка — с выгрузкой для Excel и раскрытием до документов |
| Настройки | Компания и правила продаж, команда, матрица прав, журнал изменений, подготовка к работе (импорт товаров из таблицы с проверкой), подключения |

## Роли (показ, не защита)
| Роль | Видит |
|---|---|
| Владелец | всё |
| Продавец | касса, свои чеки, каталог без закупочных цен |
| Менеджер | свои клиенты, их заказы, долги и доставки; заявки представителей на подтверждение; принимает оплату |
| Представитель | телефон: «Мой день», свои точки, свои заявки, каталог с оптовой ценой и доступным |
| Бухгалтер | деньги, долги покупателей и поставщикам, закупки (просмотр), отчёты с прибылью |
| Склад | остатки, документы, сборка, карантин, приёмка; без закупочных цен |
| Диспетчер | доставки, маршруты, деньги курьеров |
| Курьер | телефон: только свои доставки |

## Проверка
- Каждый раздел проверен в браузере под всеми ролями, которым он виден, на 1440 и 1280; курьер и представитель — на телефоне 390.
- Сквозной прогон после всех правок: 231 экран, все роли и вкладки. Ошибок в консоли нет, горизонтальной прокрутки нет, шрифт только по шкале, капса нет, на экране не больше одной главной кнопки, слово «демо» — только в метке в шапке.
- Два независимых проверяющих просмотрели снимки всех ролей и нашли около 50 недочётов. Главные — цифры, которые расходились между экранами: долги, «доступно», «ниже минимума», план сотрудников. Все исправлены во втором круге, числа сверены в браузере.
- Итоговые снимки главных экранов: `output/demo-v2/`. Рабочие снимки проверки — `output/v2/`, в git они не входят.

## Что упрощено или не сделано
- Настоящего входа по паролю и защиты данных нет: роли переключаются для показа.
- Касса, WhatsApp, банк, 1С и маркировка не подключены. Чек не фискальный.
- Частичная отгрузка оформляется только складом. Самовывоз выдаётся целиком.
- Возврат на склад после неудачной доставки отменяет заказ.
- Работа без интернета у представителя показана переключателем «Нет связи», а не настоящей очередью.
- Фото товаров нет.
- Импорт из таблицы есть только для товаров. Остатки и долги показаны цифрами, а не загрузкой.
