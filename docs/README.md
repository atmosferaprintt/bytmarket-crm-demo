# CRM «БытМаркет» — проектирование

Рознично-оптовый магазин бытовой химии и товаров для дома в Астрахани. Около 1000 SKU на старте. Основание — предоставленное пользователем ТЗ; контекст других проектов не используется.

Статус: первый проектный пакет. Предложения требуют сверки с фактическими процессами. Начата реализация: локальный сервер, SQLite, каталог, клиенты, общий остаток и резервирование заказов. Касса и интеграции ещё не реализованы. Текущие возможности и ограничения — в [README приложения](../README.md). Текстовые прототипы не являются утверждённым визуальным макетом.

## Бренд

[Присланный логотип](../assets/brand/bytmarket-original.png) сохранён без изменений. Название — «БытМаркет». Брендовая основа интерфейса: тёмно-синий, зелёный, белый. Изображение является растровым исходником, а не векторным мастер-файлом или спецификацией точных цветов. Не перерисовывать логотип и не переносить стиль других проектов.

## Актуальные условия

[Уточнения и начальное заполнение](05-starting-conditions.md): один магазин, один большой склад, доставка с запуска, представители планируются. Программ учёта нет, готовая база не предоставлена. Предлагается вести основной оперативный учёт в CRM.

## Что осталось уточнить

1. Юрлица/ИП, число сотрудников и их совмещение ролей.
2. Кассовое оборудование и необходимое кассовое решение.
3. Условия опта, скидок, отсрочки и кредитных лимитов.
4. Приём денег курьерами/представителями и частичное вручение.
